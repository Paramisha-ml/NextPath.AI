## Overview

**NextPath AI** is an AI-powered Career Recommendation System developed to assist **school and college students** in making informed academic and career decisions. The system analyzes a student's educational background, academic performance, interests, strengths, career goals, and technical skills to recommend the most suitable programs and career paths.

The project provides **two separate recommendation modules**:

- **School Career Guidance** – Recommends undergraduate programs based on stream, subject performance, interests, strengths, career goals, and competitive exam preferences.
- **College Career Guidance** – Suggests suitable career domains by analyzing the student's degree program, specialization, programming skills, tools & frameworks, internship experience, projects, certifications, and career interests.

The recommendation engine uses a combination of **content-based filtering, similarity scoring, weighted rule-based decision making, and structured datasets** to generate personalized recommendations. Along with the top career recommendations, the system also provides program details such as **duration, available specializations, higher education options, career opportunities, approximate student enrollment in India, and demand insights**.

The application is built with an interactive **Streamlit** interface that offers a modern and user-friendly experience. Users can navigate through different modules, view AI-generated recommendations, save previous analyses, and explore detailed information about various academic programs and career paths.

Through this project, I gained practical experience in **Artificial Intelligence, Machine Learning, recommendation systems, data preprocessing, feature engineering, similarity-based recommendation algorithms, dataset design, JSON data management, UI development using Streamlit, and end-to-end AI application development**. I also explored real-world applications of AI in **career counseling, educational guidance, academic planning, and personalized recommendation systems**.
